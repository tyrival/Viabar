# 总览卡片任务数量设计

## 目标

在“设置 → 显示 → 视图”中新增“总览卡片任务数量”选项，可选择 1、2、3。总览项目卡片据此展示前 N 个未完成任务，每个任务可附带其第一个未完成子任务。卡片按选定数量使用固定高度，使总览网格保持整齐。

## 设置与持久化

- 新增 `OverviewCardTaskCountSettingsStore`，使用 `UserDefaults.standard` 保存本机显示偏好。
- 存储值限定为 1、2、3；历史安装没有对应 key、读取到非法值或未来产生不兼容值时，统一回退为 1。
- 设置页通过 Picker 提供 1、2、3 三个选项，并在修改后立即刷新总览卡片。
- 该选项不加入 `AppSettings`，因此不修改 SwiftData schema，不影响主库、回收站、Widget、备份与恢复流程。

## 任务选择与展示

- 沿用当前 `project.unfinishedMilestones` 的排序和过滤语义，取前 N 个未完成任务。
- 每个展示任务继续显示任务标题；若该任务有未完成子任务，则显示其第一个未完成子任务。
- 不补入已完成任务；项目剩余未完成任务少于 N 个时，只展示实际存在的任务。
- 提醒保持当前语义：只读取并显示第一个未完成任务的提醒，不为后续任务分别展示提醒。
- 项目进度环、收藏标识、上下文菜单、点击跳转和拖放排序保持不变。

## 布局

- 将任务区改为最多三组垂直排列的任务内容，每组包含一行任务及一行可选子任务。
- 每组按统一高度布局；没有子任务时保留该组的子任务空间，避免同一数量设置下因内容差异造成卡片高度或底部区域位置变化。
- 整张卡片按数量 1、2、3 分别映射到三个固定高度。数量为 1 时保持当前 187pt 高度，数量为 2、3 时在当前视觉密度基础上逐组增加固定高度。
- 提醒与进度区域仍固定在卡片底部，不随某一任务是否包含子任务而漂移。

## 本地化

- 在简体中文与英文资源中加入“总览卡片任务数量”的对应文案。
- 数字选项直接显示 1、2、3，不增加新的单位或解释性文案。

## 验证

- 静态检查设置存储对未设置值、合法值和非法值的解析结果。
- 静态检查卡片只取前 N 个未完成任务，且每个任务只取第一个未完成子任务。
- 检查提醒仍只绑定首个未完成任务。
- 检查 1、2、3 分别使用固定高度，并确保缺少任务或子任务时布局仍保持一致。
- 检查中英文资源完整性，运行 `git diff --check` 与本地化 plist 语法检查。
- 按当前任务约束，不编译、不运行测试、不提交。

## 非目标

- 不改变项目、任务或子任务模型。
- 不改变任务完成、排序、提醒或进度计算规则。
- 不将该偏好纳入备份、Widget 或跨设备同步。
- 不重构总览卡片之外的界面。
